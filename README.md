
# Kleiderspende-Prototyp

Ein kleiner Frontend-Prototyp zur Fallstudie IPWA01-01, Aufgabe 3. Das Formular nutzt Bootstrap 5.3.8 für die Basisstile der Eingabefelder; eigene CSS-Regeln ergänzen Layout, Farben und responsive Darstellung.

## Lokal starten

`index.html` im Browser öffnen. Der Prototyp braucht weder Installation noch Build-Schritt. Für die Bootstrap-Basisstile ist eine Internetverbindung nötig; ohne sie bleibt die eigene Gestaltung weitgehend verwendbar.

## Enthaltene Abläufe

- Übergabe an der Geschäftsstelle oder Abholung wählen
- Art der Kleidung und Krisengebiet auswählen
- Adress- und Terminangaben nur bei Abholung anzeigen und verlangen
- Postleitzahl auf fünf Ziffern und die ersten beiden Ziffern `10` prüfen
- Eingaben auf einer abschließenden Bestätigungsansicht zusammenfassen
- Responsive Layout, sichtbare Tastaturfokusse und verständliche Textfehler

## Grenzen des Lernprototyps

Die Geschäftsstelle mit PLZ `10115` und die Krisengebiet-Auswahl sind Demonstrationswerte. Es gibt keine Serveranbindung, Datenspeicherung, echte Terminbuchung oder Übermittlung. Die Krisengebietsliste müsste für einen echten Verein aktuell und fachlich verantwortlich gepflegt werden. Impressum und Datenschutz sind Platzhalter.
